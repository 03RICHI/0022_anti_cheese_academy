# ①課題名
アンチーズアカデミー（ANTI CHEESE ACADEMY）トップページ

## ②課題内容（どんな作品か）
- 「チーズに頼らないおいしさ」を学ぶ架空の料理スクールの、コーポレートサイト風トップページ
- HEADER / MAIN VISUAL / NEWS / PICKUP / COMPANY の5つのセクションで構成
- COMPANY では代表メッセージ、会社概要の表、沿革、アクセス（Googleマップ埋め込み）を掲載
- 会社名・代表者・所在地・ニュースなどの内容はすべて架空（ダミー）
- HTML / CSS のみで作成（ライブラリ不使用）

## ③アプリのデプロイURL
なし

## ④アプリのログイン用IDまたはPassword（ある場合）
- なし

## ⑤工夫した点・こだわった点
- **ページ内リンク**：ヘッダーの NEWS / PICKS / COMPANY を押すと、各セクションへ移動できるようにした
- **Flexboxでのレイアウト**：ヘッダー、メインビジュアル、ニュース一覧、ピックアップのカード並びを `display: flex` で組み、`justify-content` や `align-items` で配置を調整した
- **Gridでのレイアウト**：COMPANY の「代表メッセージと会社概要」「地図とアクセス情報」を `display: grid` で2列に並べた
- **ニュースの種類を色分け**：「お知らせ」「プレスリリース」「企業情報」のラベルに別々の色を付け、ひと目で種類が分かるようにした
- **沿革のタイムライン**：`::before` で縦の線、`::after` で年ごとの丸い点を描き、年表らしい見た目にした
- **デザイン**：グリーンを基調に、オレンジやピンクを差し色にして、やさしく親しみやすい雰囲気にした。ボタンやカードは角を丸くした

## ⑥難しかった点・次回トライしたいこと（又は機能）
### 難しかった点
- **要素の並べ方**：`display: flex` を指定しないと `justify-content` などの並び替えが効かず、どの要素に何を指定すればよいかを理解するのに時間がかかった
- **中央寄せ**：ピックアップの絵文字を箱の中で上下左右の中央に置く方法と、箱そのものを中央に置く方法の違いが分かりにくかった

### 次回トライしたいこと
- スマホ幅でも崩れないレスポンシブ対応にしたい
- 色を CSS 変数（`:root`）にまとめて管理したい
- 「講座を見る」「お知らせ一覧へ」を実際に動くボタン・リンクにしたい
